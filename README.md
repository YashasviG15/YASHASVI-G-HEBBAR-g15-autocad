# YASHASVI-G-HEBBAR-g15-autocad
The course developed practical skills in AutoCAD and SolidWorks, covering 2D drafting, 3D modelling, sheet-metal and assemblies. Projects included aircraft landing gear, avian-tail mechanisms, wing design, and a final Blended Wing Body UAV. The UAV incorporated VTOL and pusher configurations, providing practical experience in aerospace CAD design.
